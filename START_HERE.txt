🚀 GETTING STARTED (Windows)

  1. Double-click: setup.bat
     ↓ Installs everything automatically
  
  2. Double-click: run.bat
     ↓ Starts the web server
  
  3. Open in browser: http://127.0.0.1:5000/
     ↓ Ready to use!

───────────────────────────────────────────────────────────────

❓ WHAT DOES IT DO?

  • Uploads floorplan PDFs
  • Automatically detects rooms
  • Calculates areas in square meters
  • Estimates carpet and tile requirements
  • Let's you interactively adjust results

🔧 IF SOMETHING GOES WRONG

  • Error during setup?
    → Run setup.bat again

  • "PDF conversion failed"?
    → setup.bat handles this automatically
    → Or manually download Poppler:
       https://github.com/oschwartz10612/poppler-windows/releases/

  • Port already in use?
    → Edit .env and change FLASK_PORT=5001

  • Need help?
    → Check SETUP.md troubleshooting section
    → Run: python test_smoke.py
